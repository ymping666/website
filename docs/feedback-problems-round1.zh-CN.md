## 来源核对与边界

- [RLEF 原论文 §2.1–2.2](https://arxiv.org/html/2410.02089v2#S2)：公开测试反馈用于修复；最终使用公开及私有测试。参考策略固定为初始模型；响应概率使用 token 几何平均，因此对数比项用平均值。采样对数比允许为负，不能当作完整分布上的精确 KL。优势计算不折扣。
- [Constitutional AI 原论文 §3–4](https://arxiv.org/pdf/2212.08073)：监督阶段采用各步修订回答，偏好阶段使用归一化概率软标签；CoT 标签截断的主实验设置为 40–60。完整流程仍包含有用性数据及强化学习。
- 修订链的 `source` 字段、原则 ID 校验以及控制器返回字符串是原创教学接口，不声称是论文代码协议。软标签成对交叉熵是拆解偏好模型阶段的标准目标，不声称复现全部训练。
- 不调用模型，不生成或执行待测代码，不判定回答是否无害。数据校验或较低损失不能证明安全性。
