# 专题题单整合

将 21 个并列题单归入 6 个专题，每个专题按学习方向展示学习单元：

- Agent 与执行反馈：工具与执行；从执行反馈学习。
- 世界模型与强化学习：状态与预测动态；策略与规划。
- Attention 与 Transformer：注意力与模型结构；视觉 Transformer。
- 生成模型与 Flow Matching：扩散、引导与流；潜变量、目标与条件控制。
- LLM 系统与 AI 反馈：检索、解码与评测；原则与偏好学习。
- 神经网络与优化：卷积与池化；梯度与优化。

每个学习单元恰好归属一个专题和方向，专题题目数按 ID 去重。旧题单 URL、题目 ID、学习顺序与本地进度键保留，单元页增加父专题导航。专题页支持直接开始单元、方向锚点、中英文切换与站内搜索。

正式域名构建及 `npm run check` 通过：592 条双语内容路由，594 个 HTML 描述与分享卡片；新增覆盖完整归属、去重、导航和搜索的构建测试。浏览器验证中英文 375px 无横向溢出，专题与单元可以正常往返。
