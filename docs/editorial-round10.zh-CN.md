# 第十轮：扩散模型反向更新可视化

发布范围：新增 3 道中英文可视化题解，累计 29 道。已完成本地验收，按用户确认发布。

## 页面与教学目标

- `/zh/editorials/diffusion-reconstruct-x0/`：用已知样本合成带噪输入，观察减去预测噪声、还原信号尺度、预测误差放大。提供正负分量、零真实噪声、单坐标、空向量和 ᾱ=1 的交互。
- `/zh/editorials/diffusion-ddpm-posterior/`：拆开两项均值贡献；展示第一坐标条件高斯分布的相对密度、均值与标准差。方差只辅助理解，函数仍只返回均值。系数没有额外归一化。
- `/zh/editorials/diffusion-ddim-deterministic/`：展示一次 η=0 更新的重建与重新混合，目标累积 α 不小于当前值。验证相同噪声水平的恒等性、干净端点和预测误差，不声称演示完整网络轨迹。

英文对应页面去掉 `/zh` 前缀。原题约定、Python 实现和测试均未修改。参考资料继续放在完整代码及代表性测试之后。

## 原始资料

- DDPM：https://arxiv.org/html/2006.11239v2 ，式 (4)、(6)–(7)。
- DDIM：https://arxiv.org/html/2010.02502v4 ，§4.1、附录 D.3。明确说明该论文 α 与本题累积 ᾱ 的记号对应。
- 新图和数值示例为本站原创。概率密度图的高度缩放至峰值 1，不表示概率；数值刻度错行排列避免重叠。
